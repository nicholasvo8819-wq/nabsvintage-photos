# nabsvintage photos

Listing photos for the nabsvintage_ shop. Claude turns these into photo links for the Depop bulk listing sheet.

How to add an item:

1. Click Add file, then Upload files.
2. Drag in the item's photos. Name them 1.jpg, 2.jpg, 3.jpg and so on. 1.jpg is the cover photo.
3. Before committing, put the folder name in front of the file names, like NV-0001/1.jpg. Easiest way: drag in a whole folder named NV-0001 from your computer.
4. Click Commit changes.

Rules: one folder per item, no spaces in names, jpg or png, under 5 MB each. Keep this repo public so Depop can load the photos.
